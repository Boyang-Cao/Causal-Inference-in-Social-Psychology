# Causal Inference in Social Psychology
This project applies causal inference methods, particularly Generalized Random Forests (GRF), to research social psychology data.

## Overview

The aim of this project is to explore whether observational data can be used to estimate heterogeneous treatment effects in social psychological research.

The analysis focuses on distinguishing predictive associations from causal effects and on assessing variation in estimated treatment effects across individuals.

## Methods

- Generalized Random Forests (GRF)
- Causal forests
- Average Treatment Effect (ATE) estimation
- Heterogeneous treatment effect estimation
- Propensity-score-based adjustment
- Covariate balance and overlap diagnostics

## Tools

- R
- `grf`
- `tidyverse`
- Statistical modelling and data visualisation

## Project status

This repository contains selected code from an academic research project and is being reorganised for portfolio use.

The original research dataset is not included because of data-access and confidentiality restrictions.
